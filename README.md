# My Solution On Procedural Dungeon Generation In Unity

So, this is my try on making procedural dungeon generation on Unity using Delaunay Triangulation, MST, Cycles, A* for pathfinding. 
This project is made especially for my needs and for my game that will be using this dungeon generation.
I tried to make everything simple to understand in scripts, so other can easily understand what i have written here and also me too.

# What I'm Trying To Solve

Even if this project is especially for my game, i will make here a lot of thing that can be useful for everyone, so what i'm actually trying to solve?
1. Multi-floor Dungeon Generation - I actually finded some useful dungeon generators that have that, but i wanted to try doing something myself and also make this customizable, so in case if i wanted to have only 2 floors i can just tell generator to do that.
2. Zones - I already found one person that did that and i really liked that idea and i wanted to make it myself with my own modifications in it.
3. Huge Customizing - By that i mean that dungeon can generate what i wanted it to generate, like a forest or caves like location using Cellular Automata, also with the ability to customize their behaviour, as a indoors locations generation, etc.
